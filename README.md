## Purpose

This repository exists to validate `AI Agent Development` as a workflow-result business, not as a generic AI-agent service.

## Parent linkage

Parent repository: `Money First Business`
Parent index file: `docs/projects/ai-agent-development-index.md`

## Lead source reference

This child repo uses Dan Martell's `AI Agent Development` thesis as an upstream lead source:

- AI agents as `virtual employees`
- multi-agent systems as a business category
- labour-cost replacement as a core economic driver
- sell-before-build as a default launch logic

## Current translation rule

We do not sell `AI Agent Development` as a category.

We translate it into a buyer-facing business model with:

- one buyer
- one painful operating bottleneck
- one implementation offer
- one clear path to a paid project

## Current business model

- buyer: founder-led agencies
- buyer-facing packaging: `AI Chief of Staff`
- day-one offer: done-for-you implementation project
- later offer: optional monthly managed optimisation / maintenance

## What this repo is validating

1. Whether founder-led agencies recognise the `Chief of Staff` bottleneck as a real pain.
2. Whether that pain is strong enough to support a done-for-you implementation sale.
3. Whether the implementation project can become the first revenue layer before any software product exists.
